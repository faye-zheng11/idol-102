按 `workbench/playbooks/ux-panel.md` 召集用户体验团：

1. 看我要审什么（$ARGUMENTS）。
2. 挑 2–4 个相关席位（Norman 情感化+可用性 / Schell 游戏情感临场 / Laurel 戏剧化能动性 / Hall 对话设计），别全上。
3. 每席给最尖锐的一击（人设详见 `workbench/references/ux-advisors.md`）。
4. 综合输出：**3 个最该改的体验问题 + 1 个建议动作**。
5. 问我要不要沉淀（进对应 bet 的 `00-think.md` 或 `workbench/drafts/`）。

这支管"体验好不好、像不像真关系"；商业视角是另一支 `/think`（智囊团）。
