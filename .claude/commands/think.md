按 `workbench/playbooks/think-tank.md` 召集智囊团：

1. 看我抛的是什么（$ARGUMENTS）：一个模糊想法、一个具体疑问、还是"给并行 bet 排序"。
2. 挑 2–4 个相关席位（参谋团人物席 + 专家 skill 席），别全上。
3. 每席给最尖锐的一击；需要方法时调对应 skill（pol-probe-advisor / opportunity-solution-tree / recommendation-canvas / positioning-workshop / prioritization-advisor）。
4. 综合输出：**3 个我最该回答的质疑 + 1 个建议下一步动作**。
5. 问我要不要把结论沉淀（进对应 bet 的 `00-think.md` 或 `workbench/drafts/`）。

目的是逼我把想清楚，不是求安慰。回答完感觉舒服 = 问得不够狠。
