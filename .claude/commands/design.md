按 `workbench/playbooks/design-tech-panel.md` 召集设计与技术团：

1. 看我要审什么（$ARGUMENTS）。
2. 挑相关席位：🎨 UI/视觉（arrange/colorize/typeset）· 🧭 UX/交互（animate/critique）· 🖥️ 前端（frontend-design/adapt/harden）· ⚙️ 后端（BACKEND_STORIES + handoff/07）· 🔍 评审官（critique/audit）。别全上。
3. 每席给最尖锐的一击（人设详见 `workbench/references/design-tech-advisors.md`）；要动手产出/改 UI 就调对应 skill。
4. 综合输出：**3 个最该改的点 + 1 个建议动作**。
5. 问我要不要沉淀（进对应 bet 的 `03-build.md` 或 `workbench/drafts/`）。

这支管"设计好不好看/好不好用/做不做得出来"（落地）；商业用 `/think`，情感体验用 `/ux`。
