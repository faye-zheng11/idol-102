# Idol 102 / OPPAYA UI 规范 v2.1

本规范基于当前项目的 `index.html`、`styles.css`、`src/ui/tokens.css`、`src/ui/components.css`、`src/ui/ui-concepts.html` 与现有素材库整理。后续新增页面、组件和视觉资产应优先复用 `tokens.css` 与 `components.css` 中的变量和基础 class，避免页面各自扩散。

## 1. 产品气质

### 1.1 核心方向

主方向是 **Velvet Backstage**：深夜后台、丝绒暗面、玫瑰灯、香槟金门牌、慢热关系推进。界面应该像用户已经进入故事现场，而不是站在产品介绍页外面。

辅助方向是 **Midnight Fanlight**：粉蓝霓虹、应援灯海、梦境闪烁。它只用于互动信号、梦境异常、稀有事件和微弱环境光，不做大面积蓝紫铺色。

### 1.2 情绪关键词

- 亲密但克制：甜度低一点，暧昧和陪伴感厚一点。
- 沉浸优先：人物、场景、对话是第一层信息，装饰退后。
- 手机原生：所有界面以 390x844 移动画布为基准，不做桌面营销页。
- 剧情驱动：CTA、toast、系统提示都应服务剧情推进或关系信号。
- 轻奢后台感：玻璃、暗影、柔光、票根、宝丽来、通行证语汇。

### 1.3 第一屏原则

第一屏必须直接进入体验或登录/选择入口。不要做营销式 hero、功能说明卡片、长介绍、品牌口号堆叠。当前 Splash 允许保留品牌和登录按钮，但视觉重点应是“进入他的世界”的沉浸感。

## 2. 设计 Token

所有新增样式优先使用 `/src/ui/tokens.css`。

### 2.1 画布

- 手机基准：`--phone-w: 390px`，`--phone-h: 844px`
- 状态栏：`--status-h: 47px`
- 底部导航：`--nav-h: 68px`
- Home indicator：`--home-indicator-h: 34px`
- 桌面预览保留手机外壳；真实窄屏 `max-width: 430px` 可全屏去外壳。

### 2.2 色彩

#### 基础背景

- `--color-ink #08070d`：最深背景，替代纯黑。
- `--color-obsidian #0c0d15`：主页面暗底。
- `--color-night #141723`：夜色过渡、顶部栏底色。

#### 面板

- `--color-panel #171c25`
- `--color-panel-2 #231f2a`
- `--color-panel-3 #332737`
- 常用透明度：`rgba(..., .56)` 到 `.82`
- 玻璃描边：`--color-line rgba(255,255,255,.14)`
- 强描边：`--color-line-strong rgba(255,255,255,.22)`

#### 文本

- `--color-text #fff9ff`：主文本。
- `--color-text-soft #e9dbe4`：正文弱一点的白。
- `--color-text-muted #a99aa8`：辅助信息。
- `--color-text-faint #6f6572`：禁用、空状态、时间等。
- `--color-cream #fff6ec`：暖白，用于剧情文本和暖色卡片上的反衬。

#### 品牌与状态

- `--color-rose #ff8aae`：主互动色，按钮、用户气泡、选中态、新消息、新记忆。
- `--color-rose-deep #c25b84`：主按钮渐变末端、深玫瑰阴影。
- `--color-gold #f6cf8b`：会员、邀请、系统提示、阶段、关系进度。
- `--color-gold-soft #d9aa68`：弱金色标签和次级剧情信号。
- `--color-neon #70e7ff`：梦境、异常、稀有高亮。
- `--color-violet #b897ff`：梦境层次和稀有状态。
- `--color-danger #ff5d78`：删除、错误、梦境崩坏。

### 2.3 色彩使用比例

- 暗底与影像：70%-80%
- 玻璃面板与暖白材质：15%-20%
- 玫瑰粉互动色：5%-8%
- 香槟金剧情信号：3%-6%
- 粉蓝/紫霓虹：不超过 3%，只做点状或边缘光。

不要把页面做成单一紫蓝渐变、纯黑背景、纯金色主题或大面积粉色界面。

## 3. 字体与排版

### 3.1 字体栈

- 正文：`--font-sans`，当前为 Inter / DM Sans / PingFang SC / Microsoft YaHei / system-ui。
- 剧情叙事：`--font-serif`，当前为 Noto Serif SC / Songti SC / serif。
- 梦境标题：`--font-display`，当前为 Playfair Display / Noto Serif SC / serif。
- Splash 品牌字可使用 Pacifico，但只用于 OPPAYA 标识。

### 3.2 字号层级

- Caption：`10px`，英文标签、状态、小图标说明。
- Meta：`12px`，时间、辅助说明、卡片 meta。
- Body：`13px` 到 `14px`，聊天气泡、选择项、列表正文。
- Body Large：`16px`，关键短句、Home 日期。
- Page Title：`18px` 到 `24px`，页面标题、场景标题。
- Character / Display：`32px` 到 `40px`，角色名、关键数字。
- Splash / Hero：`40px` 到 `58px`，只用于启动页或梦境强情绪标题。

### 3.3 字重与行高

- 正文：400-500，行高 `1.55` 到 `1.65`。
- 剧情叙事：300-500，行高 `1.7` 到 `1.85`。
- 按钮与标签：700-900。
- Display：700-900，行高 `1.0` 到 `1.12`。
- 不使用负字距。标签可大写，字距 `.18em` 到 `.24em`。

### 3.4 文案长度约束

- 底部导航：英文 1 个词，中文不超过 2-3 字。
- 主按钮：英文不超过 22 字符，中文不超过 8 字。
- 标签：英文 1-3 个词，中文不超过 6 字。
- 聊天气泡单条建议不超过 90 中文字符；长叙事拆分为多条。
- 卡片标题必须可单行截断，使用 `overflow-wrap:anywhere` 或省略。

## 4. 圆角、描边、阴影

### 4.1 圆角

- 小组件：`--radius-xs 6px`
- 卡片/列表/选择项：`--radius-sm 8px` 到 `--radius-lg 12px`
- 输入框、聊天气泡、底部栏内按钮：`--radius-xl 18px`
- 大浮层、底部导航、action sheet：`--radius-2xl 24px`
- 胶囊标签：`--radius-pill 999px`
- 手机外壳：`--radius-phone 30px`

规范上应以 8-12px 为主。不要使用大量 28px 以上的圆角卡片，除非是底部浮层、导航或 action sheet。

### 4.2 描边

- 默认玻璃描边：白色 14%-16%。
- 可点击高亮：玫瑰粉 20%-42%。
- 系统/邀请/阶段：香槟金 22%-34%。
- 错误：危险红 65%-85%，只用于异常层。

### 4.3 阴影

- 常规面板：`--shadow-panel`
- 浮层/弹窗：`--shadow-float`
- 轻 glow：`--shadow-glow`
- 金色剧情 glow：`--shadow-gold-glow`
- 蓝色梦境 glow：`--shadow-blue-glow`

阴影应柔、散、低对比。避免硬投影和明显卡片堆叠感。

## 5. 布局规则

### 5.1 页面安全区

- 页面左右边距：18px 到 24px。
- 顶部有状态栏页面：首内容通常从 54px 到 76px 开始。
- 底部有导航页面：内容底部预留 86px 到 104px。
- 聊天输入栏：底部预留 32px，避免 Home indicator 遮挡。

### 5.2 固定尺寸

以下组件必须有稳定尺寸，避免状态变化时跳动：

- 底部导航：高度 62-68px，四等分。
- 图标按钮：42px 或 48px 正圆。
- 发送按钮：40px 或 52px 正方/圆角方。
- 宝丽来缩略卡：约 112x132px。
- 宝丽来大卡：宽 282-318px，图片高 224-236px。
- 头像：30px、38px、42px、104px 四档。
- 选择按钮：最小高度 42px 到 52px。

### 5.3 层级

推荐 z-index 层级：

- 背景影像：1
- 页面 UI：5-10
- 底部导航：20
- 抽屉/通知面板：20-45
- Toast：200
- Modal/action sheet：120-130
- 全屏梦境/记忆转场：120+

背景图上的文字必须有渐变遮罩或暗色玻璃承托，不允许直接压在高亮人物脸部或复杂背景上。

## 6. 基础组件

优先复用 `/src/ui/components.css` 的基础 class：

- `ui-glass` / `ui-card`：玻璃面板。
- `ui-pill`：胶囊。
- `ui-primary-button` / `primary`：主按钮。
- `ui-secondary-button`：次按钮。
- `ui-icon-button`：图标按钮。
- `ui-input`：输入框。
- `ui-avatar`：头像。
- `ui-eyebrow`：小标签。
- `ui-ticket`：票根/邀请/剧情提示。

### 6.1 玻璃面板

适用：登录卡、成员信息卡、选择项、toast、通知面板、场景列表、弹窗。

视觉规则：

- 背景由半透明暗面 + 轻白高光 + 玫瑰低透明渐变组成。
- `backdrop-filter: blur(14px-24px) saturate(1.18)`。
- 1px 白色描边，内侧 1px 高光。
- 圆角 12px 优先，大浮层 18-24px。

### 6.2 主按钮

适用：开始、选择成员、发送邀请、保存记忆、确认。

默认样式：

- 背景：`linear-gradient(135deg, #ffd6e5 0%, #ff8aae 54%-60%, #c25b84 100%)`
- 文本：`#25101a`
- 字重：800-900
- 最小高度：48px
- 圆角：12px 或 14px
- glow：玫瑰粉 20%-30%

禁用态：透明度 `.45`，保持尺寸，不移除按钮。

### 6.3 次按钮与图标按钮

- 次按钮使用半透明暗面，不使用金色实底。
- 图标按钮优先用熟悉符号或 CSS icon。不要用 emoji 作为核心工具图标。
- 圆形图标按钮保持 42x42 或 48x48。
- 激活态改变边框、底色和 glow，不改变尺寸。

### 6.4 输入框

- 背景：白色 7%-8%。
- 描边：白色 13%-14%。
- 聚焦：玫瑰描边 62%，外发光 4px / 11%。
- 圆角：14px 到 22px。
- 文本不得被发送按钮挤压，输入区使用 `flex:1; min-width:0`。

### 6.5 Toast

- 位置：默认底部导航上方，`bottom: calc(var(--nav-h) + 24px)`。
- 宽度：270px 到 `calc(100% - 48px)`。
- 圆角：15px。
- 背景：强玻璃，暗底透明度约 88%。
- 文案：13px，居中，一句话，不超过 32 中文字符。

### 6.6 Modal 与 Action Sheet

- Scrim：黑色 52%-58%，blur 8-10px。
- Modal 宽度：`min(100%, 318px)`。
- Action sheet 底部弹出，左右 18px，底部为导航预留 92px。
- 主操作用玫瑰按钮，取消/次操作用暗玻璃。
- 删除等危险动作只把文字改为危险色，不整块铺红。

## 7. 关键业务组件

### 7.1 聊天气泡

角色气泡：

- 左侧，对齐头像时使用 `.bubble-row`。
- 背景：暗玻璃 `rgba(23,28,37,.82)`。
- 文本：`rgba(255,249,255,.92)`。
- 左下角可收小到 5px，形成聊天气泡方向。

用户气泡：

- 右侧。
- 背景：玫瑰渐变。
- 文本：深玫瑰黑 `#281019`。
- 右下角可收小到 5px。

系统气泡：

- 居中。
- 金色描边和浅金底。
- 只显示关系信号、状态变化、系统确认。

特殊气泡：

- `voiceover`：透明、居中、斜体，用于旁白。
- `error`：红色异常样式，只用于梦境崩坏/连接中断。

### 7.2 选择项

- 用暗玻璃卡承载，最小高度 42px。
- 文本左对齐，13px，行高 1.5。
- 点击态：边框转玫瑰 58%，背景加玫瑰 14%。
- 选择项之间间距 8px。
- 底部选择栈必须有从暗到底透明的渐变，保证悬浮在场景上可读。

### 7.3 底部导航

- 位置：左右 24px，底部 20px。
- 高度：62px。
- 四等分：Home / Chat / Scene / Me。
- 按钮内含图标和 10px 文案。
- 默认色：`rgba(255,249,255,.55)`。
- 激活态：玫瑰浅底、`#ffd6e5` 文本、轻 glow。
- 新消息点：玫瑰圆点，绝对定位，不影响布局。

### 7.4 阶段胶囊

- 用于 Home 中当前关系阶段。
- 位置：人物海报中下部，不遮挡脸。
- 背景：玫瑰低透明玻璃。
- 文本：15px / 800 / `#ffd6e5`。
- 宽度：最大 `calc(100% - 48px)`，长文案需截断或换短文案。

### 7.5 宝丽来记忆卡

缩略卡：

- 尺寸：112x132px 左右。
- 背景：`#fff5ea` 或 `#fffaf0`。
- 圆角：6-8px。
- 轻微旋转，范围 -4deg 到 4deg。
- 文字颜色使用纸张上的深棕 `#241d15` / `#5b5044`。

大卡：

- 宽度：282-318px。
- 图片高度：224-236px。
- 圆角：8px。
- 文本区可滚动但隐藏滚动条。
- 编辑态取消旋转。
- 新记忆可加玫瑰 glow，但不要常态高亮。

### 7.6 场景卡

- 列表卡：图左文右，`grid-template-columns: 104px 1fr`。
- 缩略图高约 116px，圆角 10-14px。
- 场景状态标签用 10px 大写/金色。
- 标题 15-16px，说明 12px。
- 卡片之间间距 12px。

### 7.7 人物选择卡

- 人物大图全屏铺底。
- 头像/人物图 `object-position: center 16%`，优先保脸。
- 底部信息卡使用暗玻璃，避免纯文字压在图上。
- 角色名 34px 左右，不强制全大写。
- Dots 激活态为玫瑰粉长胶囊。

## 8. 页面模板

### 8.1 Splash / 登录

结构：

- 星尘、柔光、品牌区。
- 主标题：最多 2 行，40px 左右。
- 副标题：12px，英文大写或短句。
- 登录卡：底部，三种登录方式，每项 52px。

注意：

- 背景允许抽象梦境，但不应出现大面积纯渐变空屏。
- 登录按钮图标必须稳定 20px，外层 30px 圆底。

### 8.2 成员选择

结构：

- 顶部一句强情绪标题。
- 全屏成员图轮播。
- 底部成员信息玻璃卡。
- 左右圆形切换按钮、dots、底部主 CTA。

注意：

- 标题不要遮脸。
- CTA 固定底部，左右 28px。
- 图片必须有底部暗渐变。

### 8.3 梦境介绍

结构：

- 全屏后台/梦境背景。
- 底部叙事玻璃卡。
- Continue 胶囊按钮。

注意：

- 叙事用 serif，17px，行高 1.8。
- 背景不够暗时加 veil。

### 8.4 梦境对话 / 真实场景对话

结构：

- 场景背景图。
- 顶部场景标题。
- 中间消息流。
- 底部选择栈或自由输入。

注意：

- 选择栈底部要避开 Home indicator 与导航。
- 梦境错误层可以红色 glitch，但持续时间短，不能影响可读性。

### 8.5 Home

结构：

- 全屏人物海报。
- 顶部角色名和 Day 信息。
- 中下部阶段胶囊。
- 底部横向记忆时间线。
- 底部导航。

注意：

- 人物脸部是主视觉，UI 避开脸部。
- 海报必须有底部 vignette，保证记忆卡可读。
- Home UI 可隐藏，但隐藏动画只改变 opacity/scale，不改变布局。

### 8.6 Chat

结构：

- 顶部头像、名称、模式和 Scene 按钮。
- 消息流。
- 底部输入栏。

注意：

- Chat header 高度稳定。
- 输入栏和发送按钮必须固定高度。
- 场景入口按钮用玫瑰透明底，不用金色实底。

### 8.7 Scene

结构：

- 页面标题。
- 场景列表或地图。
- 每个场景有缩略图、状态、标题、说明。

注意：

- 当前项目列表页应保留安静工具感，不要做营销卡片。
- 若后续改地图，pin 使用玻璃胶囊，不用 emoji 地标作为核心图标。

### 8.8 Me

结构：

- 顶部封面图。
- 头像、昵称、UID/email。
- 设置列表。

注意：

- 头像为 104px，封面高度约 214px。
- 列表每项 56px，底部细分割线。
- 危险项仅文字玫瑰/危险色。

## 9. 影像与素材

### 9.1 人物图

本地人物图集中在 `/assets/characters/`。人物图用于选择页和 Home 海报时必须：

- 使用 `object-fit: cover`。
- 优先保留脸、眼睛、上半身。
- 避免暗遮罩盖住面部。
- 背景 UI 区域可用 vignette 或渐变压暗。

### 9.2 场景图

场景图由 `/src/ui/image-library.js` 统一维护。新增场景图不要直接散落写在页面里。

远程图可以作为原型备选，但生产前应替换为可控 CDN 或本地压缩资源。所有场景图都应有：

- 暗色渐变遮罩。
- 明确地点信号。
- 与剧情关系相关的可识别物件，如公司门口、便利店、练习室、咖啡店。

### 9.3 纹理

允许：

- 轻 grain。
- scanline。
- 柔光星点。
- 宝丽来纸张质感。

禁止：

- 大面积装饰圆球。
- 无意义 bokeh。
- 过度模糊的 stock 背景。
- 影响文本可读性的强纹理。

## 10. 动效

### 10.1 基础时间

- 快速交互：`--motion-fast .18s`
- 常规状态变化：`--motion-base .28s`
- 页面/强情绪过渡：`--motion-slow .52s`

### 10.2 交互态

- 点击态：`translateY(1px) scale(.985)`。
- 激活态：改变边框、亮度、glow。
- 进入动画：`fadeUp`，14px 内轻微上移。
- 聊天气泡：`bubble`，轻微上移和 scale。

### 10.3 剧情动效

- 梦境可使用短暂 flicker、scanline、glitch。
- 记忆保存可使用宝丽来 pop 和粒子淡出。
- Home 海报可使用轻微 breathing。

动效不能造成布局位移、文字遮挡或长时间闪烁。关键操作必须在 300ms 内给出反馈。

## 11. 文案规范

### 11.1 语言风格

项目当前是中英混合界面，偏国际化原型。英文适合按钮、模式、状态；中文适合剧情解释、旁白和用户可读说明。不要在同一颗按钮里混用中英。

### 11.2 大小写

- 导航：Title Case，例 `Home` / `Chat`。
- 英文标签：可全大写，配 `.18em-.24em` 字距。
- 按钮：短动词或动宾短语，例 `Continue`、`STEP INTO HIS WORLD`。
- 系统提示：少量中文或英文短句，不写长说明。

### 11.3 状态语气

- 成功：像关系推进，不像后台日志。
- 错误：只在梦境异常时技术化；普通错误应温和。
- 删除/登出：直接清楚，不暧昧。

## 12. 可访问性与可读性

- 主要点击目标不小于 40x40px。
- 关键按钮文字对比必须足够，玫瑰按钮使用深色文字。
- 背景图上文字必须有遮罩、阴影或玻璃底。
- 禁止文字压住人物脸部。
- 输入框聚焦态必须明显。
- 可滚动区域隐藏滚动条可以保留，但必须能自然滚动。
- 图标按钮必须有 `aria-label`，尤其是左右切换、封面编辑、头像编辑。

## 13. CSS 组织

### 13.1 文件职责

- `src/ui/tokens.css`：设计变量，只放 token。
- `src/ui/components.css`：跨页面基础组件。
- `styles.css`：当前原型页面样式和 v2.0 视觉覆盖层。
- `src/ui/components.js`：复用 class 名组合。
- `src/ui/copy-library.js`：共享 UI 文案。
- `src/ui/image-library.js`：共享图片路径。

### 13.2 新增样式规则

- 新增通用样式先进 `components.css`。
- 页面私有样式进 `styles.css` 或对应模块注入样式，但要复用 token。
- 不直接新建一组相近色值；确实需要新色，先补 token。
- 不复制一套新的按钮、输入框、卡片体系。
- 避免 `!important`，只在已有遗留覆盖无法短期拆解时使用。

## 14. 禁止项

- 不做营销式落地页 hero。
- 不用大面积单一紫/蓝渐变。
- 不用纯黑大空屏替代场景。
- 不把 UI 卡片套在另一个装饰卡片里。
- 不使用过大的圆角卡片堆叠。
- 不使用 emoji 作为核心导航或工具图标。
- 不让按钮文字溢出、聊天气泡超宽、导航图标跳动。
- 不让文本遮挡人物脸、关键地点或 CTA。
- 不用 `AVG(rate)` 这类数据分析口径写进 UI 文案；指标解释应来自业务定义。

## 15. 新页面验收清单

新增或改版页面提交前检查：

- 是否使用 390x844 画布验证过。
- 是否复用了 `tokens.css` 的颜色、字号、圆角和动效。
- 是否至少有一个真实人物/场景/记忆视觉资产支撑页面。
- 主要 CTA 是否清楚且不超过推荐长度。
- 背景图上的文本是否可读。
- 底部导航、输入栏、Home indicator 是否互不遮挡。
- 所有固定格式组件是否有稳定尺寸。
- 触摸目标是否不小于 40px。
- 错误、空态、禁用态是否存在。
- 页面整体是否仍然是 Velvet Backstage，而不是霓虹营销页或普通聊天工具。
