# Idol 102 UI 规范 v2.0

## 设计方向
- 主方向：Velvet Backstage。参考 `style-02-velvet-backstage.svg` 与第二张概念图，强调后台休息室、玫瑰灯、香槟金门牌、慢热剧情推进。
- 辅助方向：Midnight Fanlight。参考 `style-01-midnight-fanlight.svg` 与 SET 1/SET 2，用粉蓝霓虹作为互动信号，不做大面积蓝紫铺色。
- 第一屏必须是可进入体验的沉浸 UI，影像和角色关系是主信息，不做营销式落地页。

## 色彩
- 背景：`#08070D`、`#0C0D15`、`#10131B`，避免纯黑。
- 面板：`#171C25`、`#231F2A`、`#332737`，以 60%-82% 透明度叠加毛玻璃。
- 主互动色：`#FF8AAE`，用于主按钮、用户气泡、选中态、通知和可点击 glow。
- 会员/邀请色：`#F6CF8B`，用于阶段、进度、票根、系统提示。
- 辅助霓虹：`#70E7FF`、`#B897FF`，仅用于梦境、错误、稀有事件或星光点缀。
- 描边：白色 14%-22%，玫瑰粉描边 20%-42% 只用于高亮组件。

## 字体
- 正文：`Inter`、`DM Sans`、`PingFang SC`、系统 sans-serif。
- 剧情文字：`Noto Serif SC` 可用于旁白、长叙事、回忆正文。
- 梦境/品牌标题：`Playfair Display` 只用于开屏或强情绪标题。
- 不使用负字距；标签可以大写并使用 `0.20em` 到 `0.24em` 字距。

## 字号层级
- Caption：10px，用于英文标签、状态、小图标说明。
- Meta：12px，用于时间、辅助信息、卡片说明。
- Body：13px 到 14px，用于聊天气泡和列表正文。
- Card Title：16px，用于场景卡、邀请卡、章节卡。
- Page Title：18px，用于页面标题。
- Display：32px 到 40px，用于角色名和关键数字。
- Hero：58px，仅用于开屏梦境标题。

## 圆角
- 组件圆角以 8px 到 12px 为主，符合 reference 中更利落的手机 UI。
- 输入框、聊天气泡、列表卡：18px 以内。
- 底部导航和大浮层：18px 到 24px。
- 胶囊标签：999px。
- 手机外壳：30px；真实移动端全屏时可去掉外壳圆角。

## 间距与布局
- 手机画布基准：390x844。
- 页面左右安全边距：18px 到 24px。
- 卡片内边距：12px 到 16px。
- 顶部状态区后首内容从 54px 到 58px 开始。
- 底部导航：左右 24px、底部 20px、高度约 62px。
- 固定格式元素必须设置稳定尺寸，避免按钮、宝丽来、头像、导航项因文案或状态变化跳动。

## 组件
- 玻璃面板：使用 `linear-gradient + rgba + blur(20px)`，描边白 14%，内高光 14%-18%。
- 主按钮：玫瑰粉渐变 `#FFD6E5 -> #FF8AAE -> #C25B84`，文字深玫瑰黑。
- 次按钮/标签：半透明暗面板，必要时加玫瑰粉或香槟金描边。
- 聊天气泡：对方为暗玻璃；用户为玫瑰渐变；系统提示为香槟金浅底。
- 底部导航：使用线性图标优先，文字 10px，激活态为玫瑰粉暗底和轻 glow。
- Home：角色影像全屏，顶部身份信息叠加，阶段胶囊位于中下部，记忆宝丽来横向排列。
- 记忆卡：暖白宝丽来材质，8px 圆角，玫瑰 glow 只在保存/新记忆状态出现。
- 场景邀请：使用大图背景 + 暗玻璃事件列表 + 底部主按钮，按钮 glow 不超过页面宽度。

## 动效
- 点击态：`translateY(1px) scale(.985)`。
- 激活态：边框、亮度和 glow 变化，不做大幅弹跳。
- 页面转场：淡入、轻微上移、轻微 scale。
- 错误/梦境状态可使用短暂 scanline 或 neon flicker，但不能影响可读性。

## 禁止项
- 不使用大面积单一紫/蓝渐变。
- 不使用营销页 hero 卡片布局。
- 不使用圆角过大的卡片堆叠。
- 不让文本遮挡人物脸部、按钮文字溢出或导航图标跳动。
- 不用 emoji 作为核心工具图标；优先使用 CSS 图标或图标库。
