# Idol 102 UI 规范

## 视觉基调
- 关键词：果味极简、高级暗黑、轻毛玻璃、温柔亲密、影像优先。
- 背景不使用死黑，统一从 `#08090b` 到 `#181a1f` 的层次暗色。
- 高亮色只保留低饱和暖金 `#c9a96e`，辅助可少量使用雾蓝、青绿、玫瑰色。

## 字体
- 正文：`Inter`、`DM Sans`、`PingFang SC`、系统 sans-serif。
- 中文叙事/标题：`Noto Serif SC`。
- 品牌/梦境标题：`Playfair Display`。
- 不使用负字距；小标签可使用大写和 `0.22em` 字距。

## 字号层级
- Caption：10px，用于英文标签与状态。
- Meta：12px，用于辅助信息、时间、说明。
- Body：14px，用于聊天气泡和列表正文。
- Body Large：16px，用于重要列表项。
- Title：22px，用于页面小标题。
- Title Large：28px，用于一级页面标题。
- Display：42px，用于角色名、主视觉信息。
- Hero：56px，仅用于启动页。

## 圆角
- 小控件：10px。
- 常规按钮/输入框：14px。
- 卡片和面板：18px。
- 大面板/抽屉：24px 到 30px。
- 胶囊：999px。
- 手机外壳：44px。

## 间距
- 基础步进：4px。
- 页面左右安全边距：18px 到 28px。
- 卡片内边距：12px 到 18px。
- 主功能区垂直间距：20px 到 28px。
- 底部导航保持 24px 左右边距、20px 底部边距。

## 组件
- 玻璃面板统一使用 `.ui-glass` 或 `.ui-card`。
- 主按钮统一使用 `.ui-primary-button` 或现有 `.primary`。
- 图标按钮统一 44px 圆形，使用 `.ui-icon-button`。
- 输入框统一半透明底、1px 淡边、focus 暖金光晕。
- 聊天气泡：对方为深玻璃，用户为暖金渐变，系统信息居中半透明。

## 动效
- 点击态：`translateY(1px) scale(.985)`。
- 悬浮/激活态只使用轻微亮度、边框和阴影变化。
- 页面转场优先柔和淡入、轻微 scale，不做大幅弹跳。
