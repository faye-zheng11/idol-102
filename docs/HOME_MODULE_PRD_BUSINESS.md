# Home 模块 PRD（产品功能版）

> 本文说明 Home 模块的用户故事、产品意图、页面功能、交互逻辑、动效要求、边界处理和验收标准。  
> 本文不定义接口名称、字段名称、数据表结构或具体技术实现方式，这些由开发根据业务需求自行设计。

## 1. 用户故事

作为一个完成 OB 的用户，  
我希望一进入主站就能看到我和当前角色的海报、相识天数和已经发生过的回忆，  
这样我会感觉我们的关系已经开始，并且正在被时间记录下来。

作为一个经常完成 Scene 的用户，  
我希望每次共同经历都能被收进 Home 的故事线，  
这样我可以随时回看我们去过哪里、经历过什么、那一天有几个 moment。

作为一个喜欢整理回忆的用户，  
我希望可以点开某一天的回忆，查看每个 moment 的拍立得、回放当时的 Scene 聊天，也能修改展示图和正文，  
这样这些回忆不只是系统生成的记录，也能变成我自己愿意保存的关系纪念。

## 2. 产品意图

Home 是关系沉淀页。

它不是信息流，也不是普通个人主页。它要完成三件事：

1. 让用户一眼看到“我现在正在和谁建立关系”。
2. 让用户看到“我们认识多久了”。
3. 让用户看到“我们已经共同经历过什么”。

Home 的核心体验是：

- 当前角色海报
- 角色昵称
- 相识天数
- 按日期聚合的故事线
- 点击故事线后展开的 Moment 拍立得

## 3. 名词统一

为了避免混淆，本文统一使用以下叫法：

| 名词 | 指什么 | 出现位置 |
| --- | --- | --- |
| 故事线日期卡 | Home 底部横向故事线里的一张卡，代表某个有 Scene 记忆的日期 | Home 主页面 |
| Moment 拍立得卡 | 点击某个故事线日期卡后，展开看到的具体 Scene / OB moment 卡 | 拍立得预览层 |
| Moment | 某一天里的一个具体共同经历，例如一次 OB 楼下偶遇或一次 Scene | 拍立得预览层 |
| Memory Replay | 某个 Moment 对应的只读 Scene 聊天快照 | 拍立得预览层进入 |

一句话理解：

- Home 横向那排是“故事线日期卡”。
- 点开后看到的大卡是“Moment 拍立得卡”。

## 4. 模块范围

Home 模块包含：

1. Home 主页面
2. 当前角色海报
3. 角色昵称和相识天数
4. 多角色切换
5. Home 海报修改
6. 故事线日期卡
7. Moment 拍立得预览
8. Memory Replay
9. Moment 编辑
10. 从 Scene `Collect Memory` 回到 Home 的定位和闪烁动效

## 5. 核心规则

以下规则不能改：

1. Home 必须在 OB 完成后才开放。
2. OB 完成后默认落地 Home。
3. OB 完成后 Home 至少有首位角色和第一条 OB moment。
4. Home 当前角色必须是已添加角色。
5. 当前角色海报全屏铺底。
6. 角色昵称跟随 Chat Settings 的角色昵称全局同步。
7. Home 海报默认来自角色配置，也可以被用户修改。
8. 用户可以在 Home 点击海报修改当前角色 Home 海报。
9. 相识天数按用户本地时区计算。
10. 已添加多个角色时，Home 支持左右切换角色。
11. 切换角色后，海报、昵称、相识天数、故事线都切换为该角色的数据。
12. 故事线只展示有 Scene / OB moment 的日期。
13. 没有 Scene 的日期不占故事线日期卡。
14. 一天多个 moment 合并到同一天故事线日期卡。
15. 点击故事线日期卡后，进入该日期下的 Moment 拍立得预览。
16. Memory Replay 只读，不可发送、不可修改消息。
17. 编辑 Moment 只影响用户展示层，不影响角色记忆和原始 Scene 记录。

## 6. Home 主页面

### 6.1 页面目的

让用户看到当前关系状态和回忆入口。

Home 第一眼应该像“我和这个角色的关系空间”，不是普通 Dashboard。

### 6.2 页面结构

Home 主页面包含：

- 全屏角色 Home 海报
- 左上角角色昵称
- 左上角相识天数
- 多角色切换暗示按钮
- 底部故事线日期卡区域
- 当前日期锚点
- 底部导航 Home / Chat / Scene / Me

Home tab 高亮。

### 6.3 视觉要求

- 角色海报是第一视觉，占据全屏背景。
- 海报上需要有暗色渐层或遮罩，保证昵称、天数和故事线可读。
- 故事线日期卡位于页面下方、底部导航上方。
- 页面不要像营销落地页，也不要像普通相册；要像关系回忆空间。

## 7. 当前角色海报

### 7.1 展示规则

- Home 全屏展示当前角色 Home 海报。
- 默认海报来自角色配置。
- 如果用户修改过该角色 Home 海报，则展示用户修改后的海报。
- 不同角色拥有各自的 Home 海报。

### 7.2 修改入口

Home 页面支持用户点击当前海报修改 Home 海报。

点击海报后，弹出底部操作菜单：

- `Restore Default`
- `Take Photo`
- `Choose from Album`
- `Cancel`

### 7.3 修改规则

- `Restore Default`：恢复该角色默认 Home 海报。
- `Take Photo`：调用拍摄入口，完成后替换该角色 Home 海报。
- `Choose from Album`：从相册选择图片，完成后替换该角色 Home 海报。
- 修改成功后，Home 立即展示新海报。
- 修改失败时 Toast 提示，保留原海报。

### 7.4 与 Chat Settings 的关系

Chat Settings 中的 `Change Home Poster` 和 Home 海报点击修改，改的是同一件事：当前角色的 Home 海报。

无论用户从哪里修改，Home 都要展示最新结果。

## 8. 角色信息

### 8.1 角色昵称

Home 左上角展示当前角色昵称。

昵称规则：

- 默认取角色原始昵称。
- 如果用户在 Chat Settings 修改过角色昵称，Home 同步展示修改后的昵称。
- 切换角色后，昵称切换为对应角色昵称。

### 8.2 相识天数

Home 左上角展示当前角色相识天数。

文案：

```text
Day N since you met
```

规则：

- 第 1 天显示 `Day 1 since you met`。
- 相识日期从该角色被添加或通过 OB 建立关系时开始计算。
- 每天 00:00 后天数 +1。
- 00:00 按用户本地时区计算。
- 切换角色后，天数切换为该角色自己的相识天数。

## 9. 多角色切换

### 9.1 展示条件

当已添加角色数量大于 1 时，Home 展示左右切换暗示按钮。

当已添加角色数量等于 1 时，不展示切换按钮。

### 9.2 交互规则

用户可以通过以下方式切换角色：

- 左右滑动 Home 页面
- 点击左右切换暗示按钮

切换顺序：

- 按加好友先后顺序排列。
- 最后一个角色继续向后切换时，回到第一个。
- 第一个角色继续向前切换时，回到最后一个。

### 9.3 切换后刷新内容

切换角色后，以下内容全部刷新为该角色的数据：

- Home 海报
- 角色昵称
- 相识天数
- 故事线日期卡
- 当前日期锚点

### 9.4 动效要求

- 切换时海报有平滑滑动或淡入淡出动效。
- 角色昵称和天数不要跳动错位。
- 故事线切换时可轻微淡入，不要像重新加载空页面。

## 10. 故事线日期卡

### 10.1 页面目的

故事线日期卡用于展示当前角色在哪些日期产生过共同经历。

它不是按自然日铺满日历，而是只展示“有 moment 的日期”。

### 10.2 聚合规则

- 故事线按日期聚合 moment。
- 一个有 moment 的日期生成 1 张故事线日期卡。
- 一天多个 Scene / OB moment 合并在同一张故事线日期卡里。
- 没有 Scene / OB moment 的日期不生成故事线日期卡。
- 中间空白日期不占位。
- 故事线按 moment 发生日期从早到晚排列。
- 超过一屏后横向滚动，不限上限。

### 10.3 OB 第一张卡

OB 完成后：

- 当前角色故事线出现第一张故事线日期卡。
- 这张卡来自 OB 楼下偶遇。
- 它属于用户与首位角色的第一个 moment。
- 用户默认落地 Home 时，应该能看到这张卡。

### 10.4 故事线日期卡内容

故事线日期卡展示：

- 封面图
- 地点
- moment 数量

封面图规则：

- 默认取该日期第一个 moment 的场景图。

地点规则：

- 显示该日期第一个 moment 的地点。
- 不在故事线日期卡上显示事件名。

moment 数量文案：

```text
1 moment
```

或：

```text
N moments
```

### 10.5 空状态

正常情况下，OB 完成后首位角色至少有 1 张故事线日期卡。

如果异常情况下当前角色没有任何 moment，可以展示空状态文案：

```text
No memory yet
```

但不要为了凑数量展示没有日期和没有 moment 的空卡。

### 10.6 交互规则

- 用户可左右滑动故事线区域。
- 点击故事线日期卡，打开该日期的 Moment 拍立得预览。
- 没有 moment 的空状态不可点击。

## 11. 当前日期锚点

故事线下方展示当前选中故事线日期卡对应的日期。

日期格式示例：

```text
2026.05.18
```

规则：

- 默认显示当前故事线焦点卡的日期。
- 用户横向滑动故事线时，日期锚点跟随焦点卡变化。
- 如果只有 1 张故事线日期卡，日期锚点显示该卡日期。

## 12. Moment 拍立得预览

### 12.1 入口

用户点击某张故事线日期卡后，进入全屏 Moment 拍立得预览。

### 12.2 页面结构

预览层包含：

- Home 背景虚化
- 居中的 Moment 拍立得卡
- 左右滑动区域
- `Memory Replay` 按钮
- `Edit` 按钮
- 当前 moment 计数
- dots

点击拍立得卡以外区域，关闭预览，返回 Home。

### 12.3 Moment 拍立得卡内容

每张 Moment 拍立得卡对应当天的一个 moment。

卡片包含：

- 场景图
- 总结标题
- 总结正文
- 日期
- 地点

如果总结还没生成完，正文区域展示：

```text
Memory is being written...
```

### 12.4 同一天多个 moment

如果同一天有多个 moment：

- 预览内可以左右滑动切换同一天的不同 Moment 拍立得卡。
- 每个 Moment 拍立得卡与 Scene 结束时生成的拍立得样式一致。
- 底部计数和 dots 跟随当前 moment 更新。

计数文案示例：

```text
01 / 02 moments
```

如果当天只有 1 个 moment：

```text
01 / 01 moment
```

### 12.5 日期之间的切换

拍立得预览层主要展示当前日期下的 moment。

如果需要切换其他日期，用户可以关闭预览回到 Home 故事线，再点击其他故事线日期卡。

本文不要求在预览层内跨日期循环切换。

## 13. Memory Replay

### 13.1 功能说明

Memory Replay 是某个 Moment 对应的只读 Scene 聊天快照。

它用于回看当时发生过的对话，不是继续聊天入口。

### 13.2 交互规则

- 用户在 Moment 拍立得预览中点击 `Memory Replay`。
- 进入该 moment 的聊天快照页。
- 快照页只读。
- 不显示输入框。
- 不允许发送消息。
- 不允许修改消息。
- 不播放 Scene 进入过渡动画。
- 退出 Memory Replay 后，回到刚才的 Moment 拍立得预览。

### 13.3 页面表现

Memory Replay 页面可以沿用 Scene 对话快照样式，但必须明显体现只读状态。

可展示：

- 地点
- 事件 / moment 标题
- 角色
- 当时的消息流
- 返回按钮

## 14. Edit

### 14.1 功能说明

Edit 用于修改 Moment 拍立得卡的展示内容。

编辑只影响用户看到的展示层，不影响角色记忆、不改变原始 Scene 记录、不改变 Memory Replay 的原始聊天快照。

### 14.2 可编辑内容

用户可以编辑：

- 场景图
- 总结正文

用户不能编辑：

- 地点
- 日期
- 总结标题
- 原始聊天快照
- moment 所属日期

### 14.3 编辑图片

用户点击图片编辑入口后，弹出底部操作菜单：

- `Restore Default`
- `Take Photo`
- `Choose from Album`
- `Cancel`

规则：

- `Restore Default` 恢复该 moment 原始场景图。
- `Take Photo` 使用拍摄图片替换展示图。
- `Choose from Album` 使用相册图片替换展示图。
- 图片编辑成功后，Moment 拍立得卡立即展示新图。
- 图片编辑失败时 Toast 提示，保留原图。

### 14.4 编辑正文

用户点击总结正文区域后进入编辑态。

规则：

- 唤起键盘。
- 光标默认落在正文末尾。
- 用户可自由修改总结正文。
- 编辑后自动保存。
- 自动保存成功后，预览卡展示新正文。
- 自动保存失败时 Toast 提示，并尽量保留用户当前编辑内容。

## 15. 从 Scene 回到 Home

### 15.1 Collect Memory

Scene 结束后展示拍立得卡，用户点击 `Collect Memory` 后进入 Home。

Home 需要：

- 切换到该 Scene 所属角色。
- 定位到该 Scene 所属日期的故事线日期卡。
- 让对应故事线日期卡播放闪烁动效。

### 15.2 总结未完成

如果用户回到 Home 时 AI 总结还没生成完成：

- 故事线日期卡仍然出现。
- Moment 拍立得预览中正文区域展示 `Memory is being written...`。
- 总结生成完成后，展示正式总结。

### 15.3 当天已有其他 moment

如果该日期已经有其他 moment：

- 不新增一个新的日期卡。
- 将新 moment 加入该日期故事线日期卡。
- 该日期卡的 moment 数量更新。
- 用户点击该日期卡后，可以在预览内切换到新增的 Moment 拍立得卡。

## 16. 实现边界说明

本节用于帮助开发和 AI 理解 Home 需要什么，不规定前端/后端具体怎么分工。

### 16.1 页面负责展示

Home 需要展示：

- 当前角色 Home 海报
- 当前角色昵称
- 当前角色相识天数
- 当前角色故事线日期卡
- 某日期下的 Moment 拍立得卡
- Memory Replay 只读快照
- Edit 编辑入口和编辑后的展示结果

### 16.2 系统需要提供的信息

为了让 Home 正常工作，系统需要能提供这些信息：

- 已添加角色列表
- 当前角色默认 Home 海报
- 用户修改后的 Home 海报
- 当前角色昵称
- 当前角色相识日期
- 当前角色有哪些有 moment 的日期
- 每个日期有几个 moment
- 每个日期的封面图
- 每个 moment 的场景图、标题、正文、日期、地点
- 每个 moment 的聊天快照
- 用户对 moment 展示图和正文的编辑结果

这些只是产品层面的信息需求，不定义接口字段名、数据表字段名或具体实现方式。

### 16.3 内容未准备好时的兜底

- 默认 Home 海报没给：先用角色占位海报。
- 用户自定义海报加载失败：先展示默认海报。
- moment 场景图没给：先用场景占位图。
- 总结标题没生成：先展示临时标题或地点名。
- 总结正文没生成：展示 `Memory is being written...`。
- 聊天快照没准备好：Memory Replay 展示 loading 或稍后重试。

## 17. 不希望出现的体验

- OB 完成后 Home 没有第一张故事线日期卡。
- Home 横向故事线出现没有 moment 的空白日期卡。
- 故事线日期卡和 Moment 拍立得卡叫法混乱，导致点击后层级不清。
- 多角色切换后，海报变了但故事线仍是上一个角色的数据。
- Home 海报点击修改后，Chat Settings 中的 Home Poster 不同步。
- Chat Settings 修改 Home Poster 后，Home 不更新。
- 相识天数不按用户本地时区变化。
- Memory Replay 可以继续发送消息。
- 从 Memory Replay 进入时错误播放 Scene 进入过渡动画。
- Edit 修改了角色记忆或原始聊天快照。
- 总结未生成时页面空白。
- Scene `Collect Memory` 回 Home 后没有定位到对应日期。
- 对应故事线日期卡没有闪烁反馈。

## 18. 验收标准

### 18.1 Home 主页面

- OB 完成后默认进入 Home。
- Home 展示当前角色全屏海报。
- Home 展示角色昵称。
- Home 展示 `Day N since you met`。
- Home 展示底部故事线日期卡区域。
- Home tab 高亮。

### 18.2 海报和角色信息

- 点击 Home 海报可以修改该角色 Home 海报。
- 修改成功后 Home 立即展示新海报。
- 恢复默认后展示默认海报。
- Chat Settings 修改 Home Poster 后，Home 同步更新。
- Chat Settings 修改角色昵称后，Home 同步更新。
- 相识天数按用户本地时区变化。

### 18.3 多角色切换

- 多角色时显示左右切换暗示按钮。
- 单角色时不显示切换暗示按钮。
- 左右滑动可以切换角色。
- 点击切换暗示按钮可以切换角色。
- 切换后海报、昵称、相识天数、故事线都切换。

### 18.4 故事线日期卡

- 故事线只展示有 moment 的日期。
- 没有 moment 的日期不占卡。
- OB 完成后出现第一张故事线日期卡。
- 一天多个 moment 合并到同一张日期卡。
- 日期卡显示该日期第一个 moment 的封面图。
- 日期卡显示地点。
- 日期卡显示 `1 moment` 或 `N moments`。
- 点击日期卡进入 Moment 拍立得预览。

### 18.5 Moment 拍立得预览

- 预览层全屏展示。
- 点击卡外区域返回 Home。
- Moment 拍立得卡展示场景图、标题、正文、日期、地点。
- 同一天多个 moment 可在预览内左右切换。
- 计数和 dots 跟随当前 moment 更新。
- 总结未生成时展示 `Memory is being written...`。

### 18.6 Memory Replay

- 点击 `Memory Replay` 进入聊天快照。
- 聊天快照只读。
- 不显示输入框。
- 不允许发送消息。
- 不播放 Scene 进入过渡动画。
- 退出后回到 Moment 拍立得预览。

### 18.7 Edit

- 点击 `Edit` 可进入编辑态。
- 可修改场景图。
- 可修改总结正文。
- 不可修改地点、日期、标题。
- 正文编辑后自动保存。
- 编辑只影响展示层，不影响原始记忆和聊天快照。

### 18.8 从 Scene 回 Home

- 点击 `Collect Memory` 后进入 Home。
- Home 切到对应角色。
- Home 定位到对应日期故事线日期卡。
- 对应故事线日期卡播放闪烁动效。
- 当天已有 moment 时，新 moment 合并进同一天日期卡。

## 19. 给开发的自由度

开发可以自行决定：

- 接口如何命名。
- 数据字段如何命名。
- Home 数据如何缓存。
- 海报上传和保存如何实现。
- 故事线日期卡如何聚合。
- Moment 预览如何分页或滑动。
- 编辑自动保存如何实现。
- loading、toast、skeleton 的具体组件实现。

但最终体验必须符合本文定义的业务规则、页面表现、交互流程、动效要求和验收标准。
