Module 01

Auth & Character Onboarding

用户第一次进入产品，从品牌氛围、登录，到选择一个 Idol 作为关系对象。这个模块决定用户是否理解“这是长期关系入口”，而不是普通聊天工具。

触发

未登录/新用户打开 App；或删除账号后重新开始。

代码

index.html、app.js 登录 action、member slider。

状态

currentUserProgress.stage 从 splash 到 select。

EntryAuthBrand

01 Splash / Login

用户打开 App 后的第一屏。用品牌、情绪氛围和三种登录方式建立产品基调。

出现条件未进入 app preview 且没有完成 onboarding。
用户动作点击 Google / Apple / Email 任一入口。
系统结果进入角色选择页；后续真实接入 auth 时这里会变成登录成功后的路由。
CharacterSelection

02 Member Select

角色选择页。当前是 Stray Kids 成员池，滑动/箭头切换，按钮进入该角色世界。

出现条件登录入口点击后，stage=select。
用户动作选择成员，点击 STEP INTO HIS WORLD。
系统结果写入 selectedMemberId、activeChatAgent，进入 Dream Intro。
Module 02

OB Dream Experience

用平行时空/梦境式 OB 帮用户建立第一次情绪连接。它是一次性体验资产，但最终要服务于真实世界关系线。

触发

用户完成角色选择后进入梦境引导。

代码

app.js 的 startDream、illusion rounds、dream reload。

状态

completedDream=false 时可进入；完成后进入 wake transition。

NarrationPre-scene

03 Dream Intro

梦境对话前的叙事卡，交代背景“演唱会后 / backstage”。

出现条件stage=dream-intro。
用户动作点击 Continue。
系统结果进入 OB Dream Chat。
Choice ChatOpening

04 OB Dream Chat · Opening

点选式梦境聊天开场。用户通过选项推进，不需要自由输入。

出现条件点击 Dream Intro 的 Continue 后。
用户动作选择对话选项。
系统结果追加 user bubble + idol replies，推进 illusion round。
ProgressionLater State

05 OB Dream Chat · Later State

OB 中后段状态，用于展示长对话/多轮选择后页面承载能力。

出现条件连续选择数轮 OB 选项。
用户动作继续选择最终选项。
系统结果触发 finale、collapse、error reload。
Module 03

Dream Collapse / Reload / Wake

梦境体验结束时，不是直接跳转，而是通过错误、reload、白光/文字流转场，把“梦境内容”转成“真实世界第一次相遇”。

触发

OB 最后一轮选择后，工作人员打断，角色离开，梦境崩塌。

代码

playDreamCollapse、onDreamReload、startTransitionStream。

风险

动效等待时间长，截图自动化时需要单独处理。

Error StateReload

06 Dream Error / Reload

梦境崩塌后的错误态。用户点击 Reload 后进入 wake transition。

出现条件Dream finale 后调用 playDreamCollapse()。
用户动作点击 [ Reload ]。
系统结果completedDream=true，路由切到 wake。
待补快照Wake TransitionReal Scene Opening

后续需要补的状态

这个模块还应该补两张：1. Wake Transition 文字流完成态；2. 点击 Open your eyes 后真实世界场景选择态。当前自动截图在 reload 可见性上中断，我会后续用短路径/调试参数单独补。

建议工程处理给 wake / real-scene 增加可直接进入的 preview query，例如 ?preview=wake、?preview=real-scene，方便 QA 和截图。
Module 04

Home & Memory Timeline

主关系入口。用户不是进“大厅”，而是回来看角色、关系阶段和共同记忆。Home 是关系连续性最重要的视觉证明。

触发

完成首次真实场景并添加联系人后；或 app preview 直接进入。

代码

renderHome、renderMemorySlots、hydrateMemoryDayOverlay。

状态

addedCharacters、relationshipStages、unlockedStoryLines。

Main AppRelationshipMemory

07 Home / Relationship Poster

角色海报 + Day count + Stage capsule + 记忆 polaroid 时间线。当前 preview 角色为 Bang Chan。

出现条件用户已有 official friend / added character。
用户动作左右切换角色；点击 polaroid 打开记忆；双击隐藏 UI。
功能目的让用户感知“他还在、关系在延续、昨天发生的事被保存”。
待补快照Memory OverlayMemory EditReplay

Home 子状态

后续建议继续补：记忆轮播浮层、编辑记忆、上传/恢复图片、Memory Replay 回放态。这些是 Home 模块的重要子功能。

触发点击 Home 底部 polaroid；点击 Memory Replay 或 Edit Memory。
工程位置renderMemoryDayCarousel、renderMemoryDetail、renderRetrogradeReview。
Module 05

Chat System

Chat 是长期关系持续存在的核心证明。当前快照是会话列表态，后续还需要补聊天详情、设置、发现角色、场景邀请卡等状态。

触发

底部导航点击 Chat；或首次加好友后自动跳转。

代码

src/modules/chat.js，包含列表、详情、设置、发现、场景邀请。

状态

officialFriends、unlockedContacts、chatStreams、pendingSceneInvite。

Chat ListUnread

08 Chat List

会话列表态，显示已添加角色、最后一句消息、未读 badge、发现入口。

出现条件至少有一个 official friend。
用户动作点击联系人进入 chat detail；点击右上发现入口添加成员。
功能目的让用户像打开常规聊天软件一样回到关系对象。
待补快照Chat DetailSettingsDiscoverScene Invite

Chat 子状态

后续需要详细拆：聊天详情页、输入态、角色设置页、改昵称/头像/背景、Discover Members、场景邀请卡、场景进行中锁定态。

触发点击联系人、右上发现、聊天内场景邀请卡、设置按钮。
工程位置renderChatDetail、renderChatSettings、renderDiscoverPage、pendingSceneInvite flow。
Module 06

Scene System

Scene 是关系容器，不是副本大厅。当前主态是城市地图，地点热点对应不同生活场景；私密空间等地点存在锁定/解锁条件。

触发

底部导航点击 Scene；或 Chat 中场景邀请跳转。

代码

src/modules/scene.js，城市地图、热点、邀请、离开确认。

状态

unlockedScenes、activeSceneSession、pendingSceneInvite。

MapHotspotsLocked Space

09 Scene Map

城市地图态。Company / Practice Room / Cafe / Mall / Park 可作为关系场景入口，Apartment 当前为锁定态。

出现条件进入 Scene 模块。
用户动作点击地图地点热点。
系统结果无 active scene 时进入地点；有 active scene 时 resume 或弹出离开确认。
待补快照Place DetailInvitation DraftActive SceneLeave Confirm

Scene 子状态

后续建议补：点击地点后的窗口/详情、事件选择、邀请文案草稿、场景聊天中、切换地点离开确认、Apartment 锁定提示。

触发点击地图 hotspot；场景中点击其他 hotspot；从 Chat 接受邀请。
工程位置handleMapPlaceClick、showPrivateSpaceLocked、playWindowZoomTransition、showLeaveConfirm。
