# radar — 情报站（AI 主动抓回来的生料）

AI 用雷达（`playbooks/radar.md`，`/radar`）从外面抓来的东西落这，按日期存：

- `YYYY-MM-DD-github.md` — GitHub 工具/skill 雷达
- `YYYY-MM-DD-insight.md` — 产品思维/用户情报
- `YYYY-MM-DD-models.md` — AI 模型变动

这是**生料/情报**，不是定稿。好东西再晋级：方法论 → `../references/`，工具 → `../../.claude/skills/`。

_（还没有情报。说"扫一下雷达"或 `/radar` 就会有第一份。）_
