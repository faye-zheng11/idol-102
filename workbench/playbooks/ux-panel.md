# 用户体验团 — Playbook

**什么时候用**：想法过完商业智囊团后（P0 第二关）；或任何时候你想从"体验/情感/像不像真关系"的角度审一个设计、一段对话、一个流程。命令 `/ux`。
**和智囊团的分工**：智囊团问"值不值得做"（商业/战略），体验团问"体验好不好、像不像真关系"（可用性/情感/沉浸）。
**AI 怎么做**：不一定全席都上。看你抛的是什么（一段对话？一个界面？一个关系节点？），挑相关席位，每席用它的视角给**最尖锐的一击**，最后综合成「3 个最该改的体验问题 + 1 个建议动作」。目的是逼出体验短板，不是夸设计好看。

---

## 席位（详见 `references/ux-advisors.md`）

| 席位 | 拷问 |
| --- | --- |
| **Norman**（情感化+可用性） | 本能/行为/反思三层各什么感受？哪层拖后腿？会不会不知道能点/点错难回头？ |
| **Schell**（游戏情感/临场） | 兴趣曲线有起伏吗？情感高点在哪？会不会一直平、腻？ |
| **Laurel**（戏剧化/能动性） | 用户是参与者还是旁观者？他的行动真改变了角色/剧情吗？ |
| **Hall**（对话设计） | 像真人在聊还是像脚本？语气/记忆/节奏出戏吗？ |

## 怎么跑

1. 明确审的对象：一段角色对话 / 一个页面 / 一个关系推进节点 / 一个新功能的体验。
2. 挑 2–4 个相关席位逐个拷问（一次 1–2 个，等你回答）。
3. 综合输出：**3 个最该改的体验问题 + 1 个建议动作**（通常是"这段对话/这个节点该怎么改得更像真关系"）。
