# references — 知识库（外部方法论）

你学到的**外部方法论 / 框架 / 别人的最佳实践**放这。区别于隔壁两个：

| 放哪 | 是什么 |
| --- | --- |
| `references/`（这里） | **外部借来的**知识、方法论、框架 |
| `../LEARNINGS.md` | **你自己跑 bet 得出的**经验复利（P5 产出、亲身验证的） |
| `../playbooks/` | 把知识里**可执行的规则**嵌进去，让 AI 跑流程时真的照做 |

## 沉淀规矩（学到新东西就这么做）

1. **全貌进这里**：新建一个 `references/<主题>.md`，留原文要点 + 出处。
2. **可执行的提炼进 playbook**：把"该怎么做"的规则加进对应阶段的 playbook（并回链到这里），否则光存着不会被用。
3. AI 在相关阶段会自动引用这些方法。
